Warung Kilat — a fast Indonesian street-food kitchen game. Tickets arrive on the order board at the top — Nasi Goreng, Mie Goreng, Sate Ayam, Es Teh Manis, and from day 2, Ayam Goreng. Click the ingredient bins (or press 1–9) in the exact order shown on the ticket to build the dish in the wok, then click SAJIKAN (or Enter) when the plate is complete. Serve fast for a bonus, chain serves for a combo. A wrong ingredient costs 5 coins and a short buzz; 3 expired orders close the warung. Each 45-second day gets faster, with shorter timers and a third ticket.

## Run it

```sh
cd game
python3 -m http.server 8080
# open http://localhost:8080
```
